# 证券代码识别

持仓来自 SEC 13F 信息表。交易代码来自按完整证券编号查询的 OpenFIGI 参考数据，不再使用旧版手工映射表。

- 数字开头的编号使用 `ID_CUSIP`，字母开头的 CINS 使用 `ID_CINS`。
- 请求限定美国市场，只接受唯一的股票类证券结果。多个不同的 ticker/composite FIGI 返回时标记有歧义，不取第一条猜测。
- 同一公司不同证券编号、股类、普通证券与期权保留独立记录。相同 ticker 对应不同编号时保留身份后缀。
- 查询结果保存在 `scripts/security_registry.json`，包含名称、ticker、FIGI、证券类型、查询时间与来源。原始响应缓存于 `.cache/openfigi/`。
- 找不到、编号格式被拒绝或结果有歧义时保留 CUSIP 和 SEC 发行人名称；持仓股数、市值、权重均保留。
- 当前查询返回的代码是参考标签，不等于历史当时的交易代码。更名、退市、旧股类和不属于普通股票的工具可能无法得到可用代码。

## 定期更新

自动更新依次执行 SEC 抓取、标识查询、全量标签应用、覆盖率审计、数据校验、分析测试与构建。只提交通过校验的数据。新增编号优先查询；已查结果默认 90 天复核。接口故障保留缓存和待查询状态，不删除持仓，也不回退到旧手工映射。

接口无密钥最多每批 10 个编号，本实现请求起点至少间隔 2.6 秒，遇到 429 按 Retry-After 延迟。全部查询可断点恢复，初次全量耗时明显长于后续增量。

`docs/security-identification-audit.json` 记录各机构最新季度的未识别数量、权重及逐项清单。数量按申报记录计算，普通证券与期权可能对应同一个编号，不应把记录数当成不同公司数。

## 已确认的旧表错误

TSM 对应台积电 874039100；Teradyne 880770102 对应 TER。Alphabet 的 A 类 02079K305 对应 GOOGL，C 类 02079K107 对应 GOOG。后者在此前本站映射和报告说明中曾颠倒，现按 SEC 股类和 OpenFIGI 结果纠正。

来源：[OpenFIGI API](https://api.openfigi.com/v3/mapping)、各持仓季度的 SEC 原始申报链接。识别补齐只修改标签和查询状态，不改写申报的持股数量、市值、权重及证券编号。
